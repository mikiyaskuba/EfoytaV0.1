# Efoyta Investor Showcase

A responsive, static investor-facing website for Efoyta. Built with HTML, CSS, and vanilla JavaScript—no build tools or paid dependencies required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best testing, use VS Code with the Live Server extension or run a local static server.
3. Check the page on both mobile and desktop sizes.

## Before publishing — important
1. Open `script.js`.
2. The recipient email is configured as `bigdream070707@gmail.com`. The website also displays a WhatsApp link to `+251 933 773 934`.
3. Confirm the transaction reporting period and figures before sharing with investors.
4. Confirm the displayed email and WhatsApp contact details before publishing.
5. Confirm the business name, logo, and any registration details you want displayed.
6. Use real product / sourcing photography when available. The hero product imagery is CSS-generated artwork, not documentary photography.

## Contact form behavior
The form validates required fields in the browser and prepares an email using the visitor's email application. It does not store submissions on a server. For a production form that submits without requiring the visitor to have an email app, connect a trusted form backend or your own API.

## Deploy
This is a static site and can be deployed to any static hosting service that supports HTML/CSS/JS, such as Netlify, Vercel, GitHub Pages, or your preferred hosting provider. Upload the contents of this folder (not the ZIP itself) to the hosting service.
